# HTML Little Clock

[![HTML Icon](https://www.svgrepo.com/show/105535/html-file-with-code-symbol.svg)](https://wmfong0.github.io/HTML_Little_Clock/)

## Overview

**HTML Little Clock** is a simple, elegant digital clock web app built with pure HTML, CSS, and JavaScript. It displays your local time and timezone, updating every second. The design features a modern gradient background and large, readable digits, making it perfect for desktops, tablets, and mobile devices. Built for studying.

## Features

- 🕒 Real-time local time display
- 🌐 Shows your timezone and GMT offset
- 🎨 Responsive, modern UI with gradient background
- ⚡ No dependencies—just open `index.html` in your browser
- 🖼️ Includes favicon for a polished look

## Demo

[Live Demo](https://wmfong0.github.io/HTML_Little_Clock/)

## Usage

1. **Clone or download this repository.**
2. Open `index.html` in any modern web browser.
3. Enjoy your local time, beautifully displayed!
